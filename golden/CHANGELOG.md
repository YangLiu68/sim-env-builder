# RSI changelog

Each entry: what a golden run (or pre-flight testing) revealed -> what changed in the plugin
(playbook, simkit, MCP) or harness. Iteration N runs with the plugin as snapshotted in
`runs/iter_NN/plugin_snapshot`.

## Before iteration 1 (pre-flight, found while building the toolkit)
- MuJoCo 4.0: flat meshes fail to compile without `inertia="shell"` -> glb_to_mujoco always sets it.
- MuJoCo 4.0: `MjData.qM` removed -> `mj_fullM(m, d, M)`.
- numpy int vs MuJoCo enum: `x in (enum, ...)` silently False -> all comparisons use `int()`.
- Examiner: one thruster alone cannot lift a drone -> site actuators judged by applied force.
- Robots: arm link offsets doubled; car chassis collided with front wheels; keyframe qpos order
  trap -> name-based `home` keyframes generated by `Scene.write`.
- Layout: rays starting below a one-sided ground plane saw nothing -> `mj_geomDistance` support test.

## During iteration 1
- MCP SDK 2.x wrapped every string result as `{"result": "<escaped json>"}` (hard to read,
  more tokens) -> tools now use `structured_output=False` and return plain JSON text.
  (Took effect for MCP servers started after the change: shot 3+ / later iterations.)

## Iteration 1 result: void
A network/DNS outage ("Can't reach the API server (ENOTFOUND)") hit every agent ~16-19 min into
its build turn; the last two tasks failed at once; judges could not run. No skill signal.
What the partial transcripts still showed (fixed for iteration 2):
- `networkx` missing in the shared venv -> `glb_to_mujoco(collision="parts")` crashed (2 agents).
  setup_env.sh now installs networkx/gymnasium and repairs an existing venv in place;
  `parts` falls back to one hull if splitting fails.
- Duplicate `<map>` in `<visual>` when an agent added its own clip planes -> Scene merges visual
  elements (`Scene.set_visual`), never writes one twice.
- Quadruped agent started writing a Raibert stepping controller although the user said standing
  is enough -> SKILL.md rule: stay inside the confirmed scope.
Harness: transient API errors now wait for the network and resume the same session; each
iteration uses its frozen plugin snapshot; session cost is no longer double counted.

## During iteration 2 (lands in iteration 3)
- Showcase videos (user request): `simkit.showcase` renders fly-around + demo controller + every
  named camera; `simkit.smoke` writes `smoke/showcase.mp4` by default; the grader renders one for
  every golden run (live toolkit if the env's copy is older); dashboard Results plays it.
- Arm template: wrist camera pointed at its own link -> now looks past the fingertips (verified on
  a pick-and-place demo); robot marker sites moved to hidden site group 4 (red EE dot showed in images).
- Toolkit demo validated end to end: drone template flew 5 gates at the right heights; arm template
  grasped, lifted (19 cm) and placed a cube on a plate.
- Harness: optional OpenRouter provider (key file ~/.config/onellmpj/openrouter.env, opt-in via
  GOLDEN_PROVIDER=openrouter/auto with a credit check); default stays on the Claude Code login.

## Iteration 2 results (first scored round) -> fixes for iteration 3
Scores so far: quadruped_trail 89, arm_kitchen 87, drone_gates 87.5, warehouse_amr 94 (all in 2 messages,
all confirmed before building). Judge findings turned into toolkit/playbook changes:
- Short evidence: filmstrip/video covered 4 s of a 10-25 s demo -> controller.py may set
  `DEMO_SECONDS`; smoke films, checks and showcases the whole demo.
- Settling check counted objects the demo was carrying -> settling runs with robots holding home pose.
- Auto camera behind a room wall -> pull in front of occluders + swing azimuth until the view has detail.
- Tracking camera clipped into a bush -> tracking cameras pull in when scenery blocks them.
- Filmstrip second row stuck at the spawn point -> now the whole-scene overview.
- White plate blown out -> very bright mesh albedo capped at 0.86, shine reduced; day ambient .6 -> .5.
- Tiny rocks ("rocky trail" looked like grass) -> smoke `hints` list objects that are specks in every
  view; playbook: requested object classes must be clearly visible; rough terrain visible at robot scale.
- Arm blocked the overhead camera at home -> smoke warns when a fixed camera is > 15% robot at reset.
- AABB overlap false alarms (tables under tree canopies) -> exact geom distances; plant-plant ignored.
- Playbook: one task check per user-stated criterion; always report "Changes from the confirmed
  plan"; ASSETS.md flags title/role mismatches; don't re-ask what the request settles; honest colliders.

## Iteration 3 results (unseen extended tasks) + late iter_02 isaac -> fixes for iteration 4
Usage limit hit at ~13:10; recovered with harness/finish_run.py (grade+judge only) and
harness/resume_run.py (same session, "connection dropped, continue"; recorded as outage_resumes).
Scores: factory_sorting 93, robot_soccer 90.5, mars_rover 88.5, isaac_synthetic (iter_02) 86.
- Isaac alignment works: recognised Isaac fits, said it cannot run on this Mac, built+tested in
  MuJoCo, exported validated USD + isaac_smoke.py. Cost was high ($16, 68 min) -> budget rule.
- env.py baseline never reached the rover's goal -> env.py self-test must drive the env API with
  the demo controller / a reference policy and report goal reached.
- Briefs defaulted to the fanciest design (rocker-bogie, friction belt) -> simplest design is the
  default, fancy one offered as the alternative.
- 10x-upscaled pebble as boulder; stretched goal -> no non-uniform scaling > 1.3x, no upscaling > ~4x.
- Hidden scatter instances (2 of 60 rocks behind hills) cost a smoke warning -> hint, not a problem,
  when other instances of the same family are visible.
- Hanging signs/ceiling lights flagged as floating -> bodies named mounted_/hanging_/ceiling_* are skipped.
- Camera-rig visible in the data camera; pink-tinted walls -> rigs in hidden geom groups; neutral lights.
- Untested key properties (ball rolling friction) -> every key physical property gets a measured check;
  report numbers copied from the reports, never from memory.
- harbor_boat 86.5, lab_bench 89.5 (both resumed after the usage limit).
- Buoyancy lived in a Python hook only the boat's controller called -> passive tests/viewers sank
  the boat. New `world.py` convention (`simkit.world`): environment dynamics run before every step
  in examiner rollouts, actuator tests, filmstrip, showcase, env.py, view.py, dashboard viewer.
  Regression test: floating box sinks without world.py, floats with it.
- Agent loosened 4 check thresholds after seeing results -> thresholds fixed in SPEC.md before the
  first run; changes must be reported.
- Lab report missing after the usage-limit cut -> REPORT.md written early and updated incrementally;
  judge reads resume replies and REPORT.md; grader requires REPORT.md only for playbooks that ask.
- Fixed-base arms: tracking camera sat inside the links -> workspace camera from outside (filmstrip
  + showcase orbit). Grasp checks need contact on both pads; non-convex props use parts colliders.
- humanoid_gym 90.5. Iteration 3 complete: 6 unseen tasks 86.5-93 (mean 89.75).
- Golden set v2: the judge penalised "user-named" checks that only existed in the hidden judge list
  -> the simulated user now states the `checks` criteria in user_reply (from iteration 5 on).
- Filmstrip/overview row for enclosed halls was shot from outside the walls -> prefer the scene's
  own fixed overview camera (name contains overview/wide/main/top), else auto overview.
